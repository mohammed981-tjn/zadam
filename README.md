# زرعة (Sudan Agri Invest) — MVP

منصة استثمار زراعي رقمية للسودان: عرض مشاريع استصلاح وزراعة موثّقة، تسجيل مستثمرين،
استثمار بالحصص، تقارير ميدانية دورية، ولوحة إدارة. مبنية استناداً إلى دراسة
"تطبيق ذكي لإدارة الاستثمار الزراعي واستصلاح الأراضي في السودان" — هذا الإصدار
يغطي **المرحلة 1 (MVP)** من خارطة الطريق: هيكل كامل + قاعدة بيانات ومصادقة حقيقية،
بدون طبقات الذكاء الاصطناعي (تُضاف في المراحل اللاحقة).

## التقنية

- **Next.js 16** (App Router, TypeScript, Server Actions)
- **Tailwind CSS 4**
- **Supabase** (Postgres + Auth) — عبر `@supabase/ssr`

## هيكل قاعدة البيانات

| الجدول | الوصف |
|---|---|
| `profiles` | ملف كل مستخدم (مستثمر / إداري / وكيل ميداني)، يُنشأ تلقائياً عند التسجيل |
| `projects` | المشاريع الزراعية: الموقع، عدد الفدادين، سعر الحصة، حالة التمويل، مستوى المخاطرة |
| `project_updates` | التقارير الميدانية الدورية لكل مشروع |
| `investments` | طلبات استثمار المستخدمين (بانتظار التأكيد / مؤكد / ملغى) |

الحماية عبر Row Level Security: المشاريع المنشورة (غير مسودة) للعرض العام،
كل مستثمر يرى استثماراته فقط، والإداري (`role = 'admin'`) له صلاحية كاملة.

لترقية أول مستخدم إلى إداري، نفّذ يدوياً في Supabase:
```sql
update profiles set role = 'admin' where id = '<user-uuid>';
```

## الصفحات

- `/` — عرض المشاريع المفتوحة للاستثمار
- `/projects/[slug]` — تفاصيل المشروع + التقارير الميدانية + نموذج الاستثمار
- `/login`, `/signup` — تسجيل الدخول وإنشاء حساب مستثمر
- `/dashboard` — محفظة المستثمر (إجمالي الاستثمار، الحصص، تفاصيل كل استثمار)
- `/admin` — لوحة الإدارة (يتطلب `role = 'admin'`): إنشاء/تعديل المشاريع،
  تأكيد طلبات الاستثمار، نشر التقارير الميدانية
