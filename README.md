# سودجري (Sudagri) — MVP

منصة استثمار زراعي رقمية للسودان: عرض مشاريع استصلاح وزراعة موثّقة، تسجيل مستثمرين،
استثمار بالحصص، تقارير ميدانية دورية، لوحة إدارة، ومساعد ذكي يجيب عن أسئلة الزوار حول
المشاريع. مبنية استناداً إلى دراسة "تطبيق ذكي لإدارة الاستثمار الزراعي واستصلاح
الأراضي في السودان" — هذا الإصدار يغطي **المرحلة 1 (MVP) + بداية طبقة الذكاء الاصطناعي**
من خارطة الطريق.

## التقنية

- **Next.js 16** (App Router, TypeScript, Server Actions)
- **Tailwind CSS 4**
- **Supabase** (Postgres + Auth) — عبر `@supabase/ssr`
- **Google Gemini API** (`gemini-flash-latest`) — مساعد المحادثة الذكي

## هيكل قاعدة البيانات

| الجدول | الوصف |
|---|---|
| `profiles` | ملف كل مستخدم (مستثمر / إداري / وكيل ميداني)، يُنشأ تلقائياً عند التسجيل |
| `projects` | المشاريع الزراعية: الموقع، عدد الفدادين، سعر الحصة، حالة التمويل، مستوى المخاطرة |
| `project_updates` | التقارير الميدانية الدورية لكل مشروع |
| `investments` | طلبات استثمار المستخدمين (بانتظار التأكيد / مؤكد / ملغى) |
| `knowledge_entries` | قاعدة معرفة زراعية (25 إدخالاً) تُغذّي المساعد الذكي — محاصيل: القطن، القمح، الذرة الرفيعة، الدخن، السمسم، الصمغ العربي، الفول السوداني، قصب السكر، النخيل والتمور، المانجو، الخضروات؛ ثروة حيوانية: الأبقار، الأغنام، الإبل، الماعز، الدواجن، الثروة السمكية؛ مواضيع عامة: أنواع التربة، الجراد الصحراوي، حصاد مياه الأمطار؛ دول مرجعية: أستراليا، البرازيل، أمريكا، الأرجنتين، أوكرانيا وروسيا |
| `leads` | عملاء محتملون (مزارعون/مستثمرون) جمعهم المساعد الذكي عبر نموذج "تواصل معنا" — إدخال عام، قراءة للإداري فقط |
| `assistant_requests` | سجل داخلي (بدون وصول مباشر) يُستخدم فقط لتحديد معدّل الطلبات على المساعد الذكي (5/دقيقة لكل IP) |

الحماية عبر Row Level Security: المشاريع المنشورة (غير مسودة) للعرض العام،
كل مستثمر يرى استثماراته فقط، والإداري (`role = 'admin'`) له صلاحية كاملة.

لترقية أول مستخدم إلى إداري، نفّذ يدوياً في Supabase:
```sql
update profiles set role = 'admin' where id = '<user-uuid>';
```

## الصفحات

- `/` — عرض المشاريع المفتوحة للاستثمار
- `/projects/[slug]` — تفاصيل المشروع + التقارير الميدانية + نموذج الاستثمار
- `/login`, `/signup` — تسجيل الدخول وإنشاء حساب مستثمر
- `/dashboard` — محفظة المستثمر (إجمالي الاستثمار، الحصص، تفاصيل كل استثمار)
- `/admin` — لوحة الإدارة (يتطلب `role = 'admin'`): إنشاء/تعديل المشاريع،
  تأكيد طلبات الاستثمار، نشر التقارير الميدانية

## المساعد الذكي (زر 💬 العائم في كل صفحة)

يجيب على نوعين من الأسئلة، مبنياً فقط على بيانات حيّة من قاعدة البيانات (لا يختلق
معلومات غير موجودة فيها):

1. **أسئلة عن المشاريع المعروضة** (`projects`): الموقع، سعر الحصة، نسبة التمويل، المخاطرة
2. **أسئلة زراعية عامة** (`knowledge_entries`): تربة، آفات، ري، أصناف — كل إدخال مرتبط
   بدولة مرجعية (`source_country`) وملاحظة مصدر (`source_note`) توضح أنها توليف معرفي
   عام يحتاج تحققاً محلياً قبل الاعتماد عليه ميدانياً، وليست استشارة زراعية نهائية

يتطلب متغيّر البيئة `GEMINI_API_KEY` (مجاني عبر [aistudio.google.com](https://aistudio.google.com))
— بدونه يظهر رداً واضحاً بأن المساعد غير مُفعّل، دون كسر بقية الموقع.

### إضافة معرفة زراعية جديدة
عبر SQL Editor في Supabase:
```sql
insert into knowledge_entries (crop, topic, title, content, source_country, source_note)
values ('القمح', 'variety', 'عنوان', 'المحتوى...', 'الدولة المرجعية', 'ملاحظة حول موثوقية المصدر');
```
`topic` يجب أن يكون واحداً من: `soil`, `pest`, `water`, `variety`, `institutional`, `general`.
